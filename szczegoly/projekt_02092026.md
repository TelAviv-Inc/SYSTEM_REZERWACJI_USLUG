# System Rezerwacji Usług - Projekt

## Opis Projektu
Projekt systemu rezerwacji usług w salonie fryzjerskim z wykorzystaniem nowoczesnych technologii backendowych i frontendowych. System umożliwia klientom rezerwację usług, pracownikom zarządzanie harmonogramem oraz administratorom pełną kontrolę nad systemem.

## Architektura Systemu
- **Backend**: Laravel 9.x z Blade
- **Frontend**: Blade templates z Tailwind CSS
- **Baza danych**: MySQL 8.0+
- **Autoryzacja**: Laravel Breeze

## Główne Moduły

### 1. Backend - Laravel + Blade
#### Struktura katalogów:
```
/backend
├── app/
│   ├── Http/
│   │   ├── Controllers/
│   │   └── Middleware/
│   └── Models/
├── resources/
│   ├── views/          # Blade templates
│   ├── css/            # Tailwind CSS
│   └── js/             # JavaScript
├── routes/
├── database/
└── config/
```

#### Główne kontrolery:
- **AuthController** - Rejestracja, logowanie, sesje
- **UserController** - Zarządzanie użytkownikami  
- **ServiceController** - Usługi i kategorie
- **EmployeeController** - Pracownicy i dostępność
- **ReservationController** - Rezerwacje i statusy

#### Główne endpointy:
```
GET    /login              # Strona logowania
POST   /login              # Logowanie
GET    /register           # Strona rejestracji
POST   /register           # Rejestracja
GET    /dashboard          # Panel główny
GET    /services           # Oferta usług
GET    /employees          # Pracownicy
GET    /reservations       # Rezerwacje
POST   /reservations       # Tworzenie rezerwacji
PUT    /reservations/{id}  # Aktualizacja rezerwacji
DELETE /reservations/{id}  # Anulowanie rezerwacji
```

### 2. Frontend - Blade + Tailwind CSS
#### Struktura katalogów:
```
/frontend
├── resources/
│   ├── views/
│   │   ├── layouts/        # Szablony Layout
│   │   ├── auth/           # Logowanie i rejestracja
│   │   ├── dashboard/      # Panel użytkownika
│   │   ├── services/       # Usługi
│   │   ├── employees/      # Pracownicy
│   │   └── reservations/   # Rezerwacje
│   ├── css/
│   └── js/
```

#### Główne widoki:
- **Authentication Views** - Login, Register forms
- **Dashboard Views** - Panel administracyjny, klienta, pracownika  
- **Service Views** - Oferta usług
- **Reservation Views** - Wybór daty i godziny
- **Profile Views** - Edycja profilu

### 3. Funkcjonalności Projektu

#### 3.1. Autoryzacja i Użytkownicy
- Trzy role: klient, pracownik, administrator
- Laravel Breeze authentication
- Kontrola dostępu na poziomie routingu i widoków

#### 3.2. System Rezerwacji
- Kolejność: usługa → pracownik → data → czas → potwierdzenie
- Logika konfliktów terminów (aplikacyjna)
- Statusy rezerwacji: oczekująca, potwierdzona, zrealizowana, anulowana

#### 3.3. Panel Użytkownika
- Panel klienta z historią rezerwacji
- Panel pracownika z harmonogramem i wizytami  
- Panel administratora z zarządzaniem usługami, pracownikami i rezerwacjami

### 4. Bezpieczeństwo
- Haszowanie haseł z użyciem Bcrypt
- Walidacja danych po stronie serwera
- Zabezpieczenie przed XSS
- Kontrola sesji i uprawnień
- Ochrona przed atakami CSRF

### 5. Deployment
- Backend Laravel na serwerze z Apache/NGINX
- Frontend Blade jako dynamiczne strony
- Docker (opcjonalnie)
- CI/CD Pipeline

### 6. Narzędzia i Biblioteki
